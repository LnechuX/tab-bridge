# Tab Bridge — выпуск для всех

Пошаговый план, тексты для каталогов и юридические шаги. Это не юридическая консультация: перед платной версией стоит показать документы юристу.

## 1. Сборка

```
python3 tools/build.py
```

В `dist/` появятся:
- `tab-bridge-chromium-<версия>.zip` — для Opera add-ons (оттуда ставит Яндекс Браузер) и Chrome Web Store;
- `tab-bridge-firefox-<версия>.zip` — для addons.mozilla.org. Архив проверен официальным `addons-linter`: 0 ошибок и 0 предупреждений.

Код не минифицирован и не собирается сборщиком, поэтому исходники отдельно прикладывать не нужно.
Сторонние библиотеки лежат без изменений:
- `extension/lib/qrcode.js` — qrcode-generator 1.4.4: https://www.npmjs.com/package/qrcode-generator/v/1.4.4 (файл `qrcode.js`, совпадает побайтно);
- `docs/lib/jsQR.js` — jsQR 1.4.0 (только на странице для телефона, в расширение не входит).

## 2. Opera add-ons (бесплатно, для Яндекс Браузера)

1. Войдите на https://addons.opera.com/developer/ под аккаунтом Opera.
2. «Upload new extension» → `tab-bridge-chromium-*.zip`.
3. Заполните карточку (тексты ниже), категорию «Productivity», ссылку на политику: https://lnechux.github.io/tab-bridge/privacy.html.
4. Проверка занимает от нескольких дней до нескольких недель. Если долго нет ответа, напишите проверяющему во вкладке «Conversation».

## 3. Firefox Add-ons (бесплатно)

1. Зарегистрируйтесь на https://addons.mozilla.org/developers/ (нужен аккаунт Mozilla).
2. «Submit a New Add-on» → «On this site» → `tab-bridge-firefox-*.zip`.
3. Вопрос об исходном коде: «No» (код не минифицирован).
4. Вопрос о сборе данных уже заполнен в манифесте. Расширение передаёт ссылки, заголовки страниц и тексты, поэтому указаны `browsingActivity`, `websiteContent` и `personalCommunications`. При установке Firefox покажет это пользователю. Всё передаётся только в зашифрованном виде и только на устройства самого пользователя.
5. Ссылка на политику: https://lnechux.github.io/tab-bridge/privacy.html.
6. Минимальные версии: Firefox 140 на ПК и 142 на Android.

**Заметка для проверяющего (Notes to Reviewer):**

> Tab Bridge sends the current tab URL/title, selected text or a user-chosen image to the user's OWN devices. Everything is end-to-end encrypted with AES-256-GCM (WebCrypto) on the device; the 130-bit group key never leaves the user's devices (it is transferred by scanning a QR code). Encrypted payloads are relayed via the public ntfy.sh server (host permission https://ntfy.sh/*). Optional host permission https://*/* is requested only if the user configures their own ntfy server. No analytics, no remote code, no minification. Third-party library: lib/qrcode.js = qrcode-generator 1.4.4 (unmodified). To test: install, open the options page, "Показать QR-код"; the phone part is the PWA at https://lnechux.github.io/tab-bridge/.

## 4. Тексты для карточки

**Название:** Tab Bridge — вкладки между ПК и телефоном

**Кратко (до 132 знаков):**
Отправляйте вкладки, текст и скриншоты между компьютером и телефоном. Без регистрации, со сквозным шифрованием.

**Подробно:**
Tab Bridge — самый простой способ переслать открытую страницу, текст или картинку со своего компьютера на свой телефон и обратно.

• Одна кнопка: нажали — страница уже на телефоне.
• Работает с iPhone и Android, с Яндекс Браузером, Chrome, Opera, Edge и Firefox — любые сочетания.
• Без аккаунтов и регистрации: телефон подключается сканированием QR-кода.
• Сквозное шифрование AES-256: ссылки, тексты и картинки шифруются на вашем устройстве. Ключ есть только у ваших устройств, сервер видит лишь зашифрованные данные.
• Видно, что и куда отправлено: «доставлено», «открыто».
• С телефона — через меню «Поделиться» или кнопкой «Вставить и отправить».
• Скриншоты и тексты в обе стороны; большие картинки автоматически уменьшаются, чтобы уходить быстрее.
• Ничего не копится: старые файлы удаляются сами.

Нет рекламы, аналитики и сбора данных. Политика конфиденциальности: https://lnechux.github.io/tab-bridge/privacy.html

**Скриншоты для карточки:** окно расширения с кнопкой «Отправить на «iPhone»», экран телефона «Отправить на компьютер», страница «Мои устройства». Размер 1280×800 (Opera/Chrome).

## 5. Юридические шаги (РФ)

**До выпуска (бесплатная версия)** — всё уже сделано, кроме двух пунктов:
- [x] Политика конфиденциальности и пользовательское соглашение на сайте, ссылки есть в приложении и в расширении.
- [x] Автор не собирает данные: нет аналитики, внешних шрифтов и CDN, аккаунтов.
- [x] Продукт описан как личная синхронизация своих устройств, а не мессенджер: нет отправки другим людям и общих групп.
- [x] Используется только стандартное шифрование браузера (WebCrypto). В описаниях речь о «приватности», а не о «средстве криптозащиты».
- [ ] Контакт для обращений. Сейчас указан GitHub Issues. Лучше завести отдельную почту в российском сервисе и вписать её в `docs/privacy.html` и `docs/terms.html`.
- [ ] Не просить пользователей присылать личные данные в обращениях.

**До платных функций:**
1. Зарегистрироваться самозанятым в приложении «Мой налог». Регулярная продажа подписок без регистрации — это незаконное предпринимательство (ст. 14.1 КоАП). Лимит 2,4 млн ₽ в год, налог 4%, кассовый аппарат не нужен.
2. Подключить приём платежей для самозанятых (ЮKassa или Robokassa): чеки отправляются в «Мой налог» автоматически. Платёжные данные хранит эквайер, а не вы.
3. Опубликовать оферту: ФИО и ИНН, описание и цена, автопродление и его отмена, возвраты по ст. 32 «О защите прав потребителей».
4. Как только у вас появятся e-mail или данные покупателей, вы станете оператором персональных данных:
   - подать уведомление в Роскомнадзор (pd.rkn.gov.ru);
   - получать отдельное согласие на обработку данных;
   - хранить данные только в РФ;
   - обновить политику.
5. Платные функции требуют своего сервера. Без него оплату нельзя проверить: ntfy.sh бесплатный и общий, а правила GitHub Pages не разрешают коммерческие сервисы. Вероятно, понадобится свой сервер ntfy в РФ (около 300–600 ₽ в месяц) и отдельный сайт. Тогда стоит заново оценить статус «организатора распространения информации» (ст. 10.1 149-ФЗ) с юристом.

**Что учитывать уже сейчас:**
- **ОРИ (ст. 10.1 149-ФЗ).** Норма широкая. Довод в вашу пользу: у вас нет своей инфраструктуры и ключей, а сообщения ходят только между устройствами одного человека. Если Роскомнадзор пришлёт требование, отвечайте по существу, а лучше — с юристом.
- **Доступность.** GitHub и ntfy.sh — зарубежные сервисы, в РФ возможны перебои. На будущее стоит держать запасной адрес страницы и свой сервер ntfy (смена сервера уже есть в настройках).

## 6. Ограничения ntfy.sh, о которых надо знать

На одно интернет-подключение (IP):
- вложение до 2 МБ (Tab Bridge делит большие файлы на части сам);
- 20 МБ файлов за 3 часа;
- 250 сообщений в сутки;
- 200 МБ трафика в сутки.

При частых превышениях IP временно блокируется. Обычному пользователю этих лимитов хватает с запасом. Если пользователей станет много, нагрузка распределится по их собственным IP. Но условия ntfy.sh запрещают «несоразмерную нагрузку», поэтому при росте аудитории нужен свой сервер.

Название «ntfy» — товарный знак ntfy LLC. Не используйте его в названии и логотипе Tab Bridge.
