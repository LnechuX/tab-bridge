📲 Чтобы получать вкладки с компьютера

Уведомления на iPhone работают только у приложений с экрана «Домой». Установите Tab Bridge:

  1. Нажмите «Поделиться» ⎙ внизу экрана.
  2. Выберите «На экран „Домой“» → «Добавить».
  3. Откройте Tab Bridge с экрана «Домой» → «Сканировать QR-код» → наведите на тот же код на компьютере.

Уже установлено? Тогда здесь больше ничего делать не нужно.

    1

    Подключите Safari

    У Safari своя память, отдельная от приложения, поэтому его нужно подключить один раз. Он будет только отправлять — в списке получателей его не будет.

    Если Safari не открылся (так бывает на iOS 16): наведите камеру iPhone на QR-код в настройках Tab Bridge на компьютере — Safari подключится сам.

    ✓ Это и есть Safari — он подключён.

    2

    Кнопка «📤 На ПК» в Safari

    Потом на любом сайте: нажмите адресную строку → «📤 На ПК». Страница уйдёт на компьютер, и вы сразу вернётесь назад.

    Затем в Safari:

    1. В Safari на любой странице: «Поделиться» ⎙ → «Добавить в Избранное» → «Сохранить».
    2. Откройте закладки 📖 → «Избранное» → «Изменить» → нажмите на новую закладку.
    3. Название: 📤 На ПК. В поле адреса удалите всё и вставьте скопированный код → «Готово».
    Показать код
    3

    «На ПК» в меню «Поделиться»

    Работает в любом приложении: YouTube, Telegram, Яндекс, Safari. Делается в приложении «Команды» за 2 минуты.

    Затем:

    1. Откройте «Команды» → «+». Сверху нажмите на название → «Переименовать» → На ПК.
    2. Нажмите ⓘ внизу → включите «Показывать в Общем доступе» (на iOS 18 — «Показывать в меню „Поделиться“»).
    3. В блоке «Получить… из Общего доступа» выберите типы URL, Веб-страницы Safari и Текст. «Если нет входных данных» → «Получить буфер обмена».
    4. Добавьте действие «Получить URL-адреса из ввода».
    5. Добавьте действие «Закодировать URL».
    6. Добавьте действие «Открыть URL-адреса», нажмите в поле адреса, вставьте скопированное и сразу за ним выберите переменную «Закодированный URL». Готово.

    Бонус: «Настройки» → «Универсальный доступ» → «Касание» → «Коснуться сзади» → «Двойное касание» → На ПК. Тогда скопированная ссылка уходит на компьютер двумя постукиваниями по задней крышке.

    У меня iOS 16

    На iOS 16 используйте этот адрес (тогда браузером по умолчанию должен быть Safari):

    «Поделиться» → Tab Bridge

    1. Установите Tab Bridge на главный экран: меню ⋮ → «Установить приложение».
    2. В любом приложении: «Поделиться» → Tab Bridge. Ссылка уйдёт сразу, если получатель один (или выбран в настройках).

    Ещё: долгое нажатие на значок Tab Bridge → «Отправить скопированную ссылку».

    📋 Из буфера

    Скопировали ссылку → откройте Tab Bridge → «📋 Отправить скопированную ссылку». iPhone попросит разрешить вставку — нажмите «Вставить».
