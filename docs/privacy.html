Политика конфиденциальности Tab Bridge

Редакция от 7 октября 2026 г. Действует для расширения Tab Bridge для браузеров и веб-приложения Tab Bridge для телефона.

Коротко

  • Автор Tab Bridge не получает и не хранит ваши ссылки, тексты, картинки, имена устройств, IP-адреса или другие сведения о вас. У Tab Bridge нет аккаунтов, регистрации, аналитики, рекламы и cookie.
  • Всё, что вы отправляете, шифруется на вашем устройстве (AES-256-GCM). Ключ есть только на ваших устройствах. Расшифровать данные не могут ни автор, ни сервер, через который они передаются.
  • Зашифрованные сообщения на время доставки проходят через публичный сервер ntfy.sh и удаляются им автоматически: сообщения — через 12 часов, файлы — через 3 часа.

1. Кто отвечает за Tab Bridge

Tab Bridge разрабатывает и распространяет физическое лицо — автор проекта (далее — «автор»). Связаться с автором: раздел обращений проекта github.com/LnechuX/tab-bridge/issues. Не присылайте в обращениях свои ключи, ссылки и другие личные сведения.

2. Что хранится на ваших устройствах

Только на ваших устройствах (в хранилище расширения или браузера) хранятся: ключ группы ваших устройств, названия устройств, история отправленного и полученного, полученные картинки и файлы, настройки. Эти данные не передаются автору.

Полученные файлы удаляются автоматически (по умолчанию через 7 дней; срок можно изменить) и при превышении лимита места. Всё можно удалить вручную: «Память» → «Удалить полученные файлы» / «Очистить всю историю», «Отключить этот телефон», удаление расширения или данных сайта в браузере.

3. Что и кому передаётся при отправке

Сервер ntfy.sh (ntfy LLC, США) доставляет сообщения между вашими устройствами. Он получает:

  • зашифрованные сообщения и файлы — без ключа их содержимое прочитать нельзя; размер округляется (до 256 байт для сообщений и до 64 КБ для файлов);
  • случайные имена «тем» (каналов) вашей группы — по ним нельзя узнать ключ или ваши данные;
  • технические данные соединения: IP-адрес, время запросов. Их ntfy.sh использует для работы сервиса и ограничения нагрузки по своей политике: docs.ntfy.sh/privacy. По сведениям ntfy.sh, сообщения сервера также пересылаются через Google Firebase Cloud Messaging — тоже только в зашифрованном виде.

Push-уведомления на телефоне. Если вы включите уведомления, ваш браузер или телефон зарегистрирует адрес для уведомлений у своего производителя (Apple, Google, Mozilla), и ntfy.sh будет отправлять туда зашифрованные сообщения. Текст уведомления расшифровывается и формируется уже на телефоне.

GitHub Pages (GitHub, Inc., США) размещает страницу приложения для телефона. При её загрузке GitHub получает IP-адрес и технические данные браузера, как любой сайт. Ваши ссылки, тексты и ключ GitHub не передаются: они находятся в части адреса после «#», которую браузер не отправляет на сервер, или вообще не покидают устройство.

Автор не передаёт никаких данных третьим лицам, потому что сам их не получает.

4. Персональные данные

Автор не собирает и не обрабатывает персональные данные пользователей: содержимое зашифровано ключом, которого у автора нет, а технические данные соединений получают и обрабатывают в собственных целях операторы сторонних сервисов (ntfy.sh, GitHub, производители push-сервисов) по своим правилам. Если в будущем появятся функции, при которых автору нужно будет обрабатывать персональные данные (например, оплата), эта политика будет дополнена до их запуска, а обработка будет вестись в соответствии с Федеральным законом № 152-ФЗ «О персональных данных».

5. Безопасность

  • Ключ группы — 130 случайных бит; из него по HKDF-SHA256 получаются ключ шифрования и имена тем.
  • Каждое сообщение шифруется AES-256-GCM: подделать или незаметно изменить его нельзя. Каждый файл шифруется отдельным случайным ключом.
  • Ключ передаётся между устройствами только через QR-код на экране — не через интернет.
  • Если устройство потеряно, удалите его из «Моих устройств» и смените ключ (Настройки на компьютере → «Дополнительно» → «Сменить ключ»).

6. Ваши права

Вы в любой момент можете удалить все данные Tab Bridge со своих устройств (см. раздел 2). Данные на сервере ntfy.sh удаляются автоматически в сроки, указанные выше. Вопросы о данных, которые обрабатывают ntfy.sh, GitHub или производители push-сервисов, направляйте этим компаниям.

7. Изменения

Новая редакция публикуется на этой странице с указанием даты. Существенные изменения будут описаны в заметках к обновлению.

Summary in English

Tab Bridge has no accounts, analytics, ads or cookies, and its author receives no user data. Links, texts, images and device names are end-to-end encrypted on the user's device (AES-256-GCM); the key exists only on the user's own devices. Encrypted messages are relayed through the public ntfy.sh server (ntfy LLC, USA), which deletes them after 12 hours (files after 3 hours) and, like any server, sees IP addresses and request times. The phone web app is hosted on GitHub Pages. Everything stored locally can be deleted at any time in the app.
