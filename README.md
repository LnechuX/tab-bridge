# Tab Bridge — зашифрованная передача вкладок между ПК и телефоном

## Для пользователя

**Подключение (один раз):**
1. Установите расширение в браузер на компьютере. Откроется страница «Устройства и настройки», нажмите **«Показать QR-код»**.
2. **Android:** наведите камеру телефона на код → «Подключить» → разрешите уведомления.
   **iPhone:** наведите камеру на код → в Safari «Поделиться» → «На экран „Домой“» → откройте Tab Bridge с экрана «Домой» → **«Сканировать QR-код»** → наведите на тот же код.

Подключение сохраняется навсегда, пока вы сами не удалите устройство.

**Как пользоваться:**
- **С ПК:** нажмите значок Tab Bridge → **«Отправить на «iPhone»»**. Если подключено одно устройство — это единственная кнопка. Если несколько — по кнопке на каждое и «На все устройства».
  Ещё можно: правый клик по странице или ссылке, или Alt+Shift+S (на те же устройства, что в прошлый раз).
- **С телефона:** в браузере «Поделиться» → Tab Bridge (Android). Или откройте Tab Bridge, вставьте ссылку и нажмите «Отправить на …».
- **Что куда ушло:** во вкладке «Отправлено» видно, на какое устройство отправлена каждая ссылка и её статус: *отправлено → доставлено ✓ → открыто ✓✓*.
- **Мои устройства:** список есть в настройках расширения и на телефоне. Там же можно удалить устройство: оно пропадёт у всех и само отключится. Если устройство потеряно, дополнительно смените ключ (Настройки → Дополнительно).

## Для автора: подготовка, один раз

Пользователю не нужно ничего размещать: страницу для телефона один раз выкладываете вы, а её адрес вшивается в расширение.

### Шаги 1–2. Страница для телефона — уже сделано

Страница лежит в папке `docs/` этого репозитория и публикуется через GitHub Pages
(Settings → Pages → Branch `main`, папка `/docs`) по адресу **https://lnechux.github.io/tab-bridge/**.
Этот адрес уже вписан в `extension/config.js`.

### Шаг 3. Опубликовать расширение в магазинах

Без магазина пользователю пришлось бы включать «режим разработчика», а это непросто. Через магазин установка делается в один клик.

| Магазин | Для каких браузеров | Стоимость |
|---|---|---|
| [Chrome Web Store](https://chrome.google.com/webstore/devconsole) | Chrome, Яндекс, Brave, Opera | разовый взнос $5 за аккаунт разработчика |
| [Microsoft Edge Add-ons](https://partner.microsoft.com/dashboard/microsoftedge) | Edge | бесплатно |
| [Firefox Add-ons](https://addons.mozilla.org/developers/) | Firefox на ПК и Android | бесплатно |

Загружается zip-архив **содержимого** папки `extension`, то есть внутри архива сразу лежит `manifest.json`.
Проверка в магазине занимает от нескольких часов до нескольких дней.
В анкете о данных укажите, что расширение не собирает данные: ссылки шифруются на устройстве и передаются только между устройствами самого пользователя.

**Своя проверка до публикации:** `chrome://extensions` → «Режим разработчика» → «Загрузить распакованное расширение» → папка `extension`.

**Если хотите свой сервер ntfy вместо ntfy.sh:** впишите его в `config.js` (`server`) и добавьте его адрес в `host_permissions` в `manifest.json`.

## Как устроена защита

- **Сквозное шифрование AES-256-GCM.** При установке создаётся случайный ключ (130 бит), который никогда не покидает устройства пользователя. Сервер получает только шифротекст и случайное имя темы, выведенное из ключа. Длина ссылок скрыта.
- **Перенос ключа на телефон по QR.** Ключ передаётся во фрагменте адреса после `#`. Браузер не отправляет эту часть ни на GitHub, ни куда-либо ещё, а страница сразу стирает её из адресной строки.
- **Защита от подделки и повторов.** Сообщения без ключа, изменённые или отправленные повторно, отбрасываются.
- **Передаются только `http` и `https`.** Ссылки `javascript:`, `data:` и `file:` не отправляются и не открываются.
- **Вкладки сами не открываются** (можно включить в настройках).
- **Минимум прав.** Адрес вкладки доступен только в момент нажатия. Запросы идут без cookies и referrer, аналитики нет, удалённый код не загружается, на всех страницах строгая CSP.

**Что остаётся:** сервер ntfy.sh видит время и IP-адреса отправки, но не содержимое. Код страницы для телефона загружается с вашего GitHub, поэтому храните доступ к аккаунту в безопасности: включите двухфакторную аутентификацию.

## Файлы

| Файл | Назначение |
|---|---|
| `extension/config.js` | **адрес страницы для телефона — заполнить перед публикацией** |
| `extension/tb-crypto.js` | шифрование (копия лежит в `docs/`) |
| `extension/tb-core.js` | устройства, адресная отправка, статусы доставки (копия в `docs/`) |
| `extension/background.js` | отправка, приём, проверки, уведомления |
| `extension/popup.*`, `options.*` | окно расширения и страница подключения |
| `extension/lib/qrcode.js` | генератор QR-кодов (Kazuhiko Arase, MIT), работает локально |
| `docs/` | страница для телефона |
